Задание 2.3: Древовидное меню

Функция setPlusIcon(): для каждого элемента <li>, содержащего вложенный список, добавляет значок [+]. Регистрирует функцию aClick как обработчик onclick для всех ссылок.

Функция aClick(): при клике на ссылку ищет родительский <li> и вложенный список. Если вложенного списка нет — разрешает переход. Если есть — показывает/скрывает список, меняет иконку [+]/[-], запрещает переход.
