## Задание 3.2: Бонусный счёт

**Описание:** При переводе заказа в статус «Завершён», если сумма заказа больше 5000 ₽, на бонусный счёт пользователя начисляется 5% от стоимости товаров (без учёта доставки).

**Расположение:** `task3-2-bonus/`

**Установка:**
1. Скопируйте папку `task3-2-bonus/` в `/bitrix/modules/`
2. Зайдите в Marketplace → Установленные решения
3. Найдите модуль "Бонусная система" и нажмите "Установить"
4. Модуль автоматически зарегистрирует обработчик события `OnSaleStatusOrder`

**Принцип работы:**
- Обработчик отслеживает изменение статуса заказа
- При переходе в статус "F" (Завершён) проверяется сумма товаров
- Если сумма > 5000 ₽, вычисляется 5% от цены товаров (без доставки)
- Бонусы записываются в пользовательское поле UF_BONUS_BALANCE

## Задание 3.3: FAQ с email-уведомлениями

**Описание:** Инфоблок FAQ (анонс = вопрос, Email пользователя в отдельном свойстве). При заполнении детального описания (= ответа) отправляется письмо пользователю через почтовый шаблон.

**Расположение:** `task3-3-faq/`

**Установка:**
1. Скопируйте папку `task3-3-faq/` в `/bitrix/modules/`
2. Установите модуль через Marketplace
3. Создайте инфоблок с кодом `faq` и добавьте свойство EMAIL (строка)
4. Модуль автоматически зарегистрирует:
   - Обработчик события `OnAfterIBlockElementUpdate`
   - Почтовый шаблон "FAQ_ANSWER"

**Настройка почтового шаблона:**
- Тип события: FAQ_ANSWER
- Можно редактировать через Настройки → Почтовые шаблоны
- Доступны макросы: #USER_EMAIL#, #QUESTION#, #ANSWER#

## Задание 3.4: Компонент списка элементов ИБ

**Описание:** Кастомный компонент выводит список элементов инфоблока с названием, описанием и названием раздела. API-запросы кэшируются.

**Расположение:** `task3-4-component/`

**Установка:**
1. Скопируйте папку `infoblock.list/` в `/bitrix/components/custom/`
2. Подключите компонент на странице:

```php
<?php
$APPLICATION->IncludeComponent(
    "custom:infoblock.list",
    "",
    [
        "IBLOCK_ID" => 1,
        "SORT_BY" => "SORT",
        "SORT_ORDER" => "ASC",
        "ELEMENT_COUNT" => 10,
        "CACHE_TIME" => 3600,
    ]
);
?>
```

**Параметры:**
- IBLOCK_ID - ID инфоблока
- SORT_BY - поле сортировки
- SORT_ORDER - направление сортировки
- ELEMENT_COUNT - количество элементов
- CACHE_TIME - время кэширования (сек)

## Задание 3.5: Кастомное свойство

**Описание:** Множественное свойство с настройками: количество пустых полей, включение индекса сортировки, ширина поля. После сохранения значения сортируются.

**Расположение:** `task3-5-property/`

**Установка:**
1. Скопируйте папку `task3-5-property/` в `/bitrix/modules/`
2. Установите модуль через Marketplace
3. Тип свойства "Строка с сортировкой" будет доступен при создании свойств инфоблока

**Использование:**
1. Создайте свойство инфоблока
2. Выберите тип "Строка с сортировкой"
3. В настройках укажите:
   - Количество пустых полей для нового элемента (по умолчанию 3)
   - Показывать поле сортировки (да/нет)
   - Ширина поля ввода (px, по умолчанию 200)

**Особенности:**
- При сохранении элемента значения автоматически сортируются
- Несколько таких свойств на одной форме не конфликтуют
- API возвращает отсортированные значения
